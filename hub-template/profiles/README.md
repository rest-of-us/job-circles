# Profiles

One file per member, named `<github-username>.json` in lowercase, matching the profile's `id`. Only `*.json` files are published.

Start from an entry in the [sample profiles](https://rest-of-us.github.io/job-circles/profiles/demo.json) or the [profile builder](https://rest-of-us.github.io/job-circles/join.html). There are no fields for dates of study, employment dates or years of experience, and the schema rejects any field it doesn't define.
