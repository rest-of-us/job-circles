# Middle East (Western Asia) profiles

Profiles for the Middle East (Western Asia) hub. Each file is `<github-username>.json`, must pass [`../schema.json`](../schema.json) and must have `"region": "middle-east"`.

The easiest way to add one is the form at https://rest-of-us.github.io/job-circles/join.html. Pick your country and it sends your profile here, fills in the file for you and opens a pull request.

When a pull request is merged, the **Build feeds** workflow merges every file here into `../middle-east.json`, which the site reads.
